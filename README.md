# Ditdah.uk

A Morse code practice site that works with VBand USB adapters. It supports paddle and straight keys and decodes what you send in real time.

**Try it at [ditdah.uk](https://ditdah.uk).**

## Features

- **Key modes:** paddle or straight key.
- **Live decoding:** shows the text as you key it.
- **Speed and tone:** adjustable WPM and sidetone pitch.
- **VBand support:** works with VBand USB adapters.

Built with Svelte, TypeScript and the Web Audio API.

## Running it locally

```sh
npm install
npm run dev
```

`npm run build` makes a production build and `npm run preview` serves it.
